# Rob West Web Build

Create a complete, production-ready, modern 4-page website for a local plumbing and handyman business called "Rob West Plumbing & Handyman".

The website should feel like a genuine, established local trades business website — trustworthy, professional, approachable and practical — rather than a generic agency, SaaS or corporate template.

The primary goal of the website is to generate phone calls and enquiries from local homeowners. Prioritise conversion, clarity, mobile usability and trust throughout the design.
